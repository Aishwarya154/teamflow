TeamFlow — Project Requirements
Project Overview
TeamFlow is a collaborative project management platform that helps teams manage projects and tasks.

Features
User registration and login

Create workspaces and projects

Add team members to projects

Create and assign tasks

Set deadlines and priorities

Track task status

Add comments to tasks

View project progress on a dashboard

Backend: Python and Django REST Framework
