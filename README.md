
TeamFlow
Collaborative project management platform built by a student engineering team.

About the Project
TeamFlow is a full-stack web application designed to help teams organise projects, assign tasks, track progress, and collaborate efficiently in one place.

The project is developed collaboratively using industry-standard software development practices, including Git, GitHub, feature branches, pull requests, code reviews, and team-based development.

Features
User registration and login

Workspace and project management

Team member management

Task creation and assignment

Deadlines and priorities

Task status tracking

Comments and collaboration

Project progress dashboard

Technology Stack
Frontend: React

Backend: Python and Django REST Framework

Database: MySQL

Version Control: Git and GitHub

Project Structure
backend/ — Django backend application

frontend/ — React frontend application

docs/ — Requirements and API documentation

Development Workflow
Create a Git branch for each feature.

Implement and test the assigned task.

Push the feature branch to GitHub.

Open a pull request for review.

Merge approved changes into the development branch.
